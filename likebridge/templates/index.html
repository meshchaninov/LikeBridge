Синхронизация

Для новых лайков и обработки старых. Уже поставленные заявки сохраняют свой режим; его можно выбрать в карточке.

Выбираем лучший результат с оценкой не ниже порога, даже если есть похожие варианты. Оценка сравнивает название, исполнителя и год; это не вероятность. Ниже порога — ручной выбор. Сохранение настроек также возвращает подходящие ожидающие выбора заявки в обработку. При выключенной автоматике все новые совпадения ждут твоего выбора.

Маленький аппетит

Один процесс, один поток синхронизации, встроенная SQLite. Без Redis, отдельной базы и JavaScript-сервера.
